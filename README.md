# Group 4 Project

## Database setup

The `anonymous_feedback` table has been created in `cis440sum26team4`. Replace
`CHANGE_ME` in the `WorkplaceFeedback` connection string in
`ProjectTemplate/Web.config` with the database password in your local copy only.
Do not commit the real password.

## Run

Open `ProjectTemplate.sln` in Visual Studio, restore NuGet packages, and run the
web project with IIS Express. The submission page is `index.html`.
